TECHSPHERE PK - WEEK 2 PORTFOLIO

Files:
- index.html
- style.css
- script.ts       <- TypeScript source
- script.js       <- compiled browser JavaScript output

How to run:
1. Open the folder in VS Code.
2. Open index.html with Live Server.
3. Click "Switch to Light Mode" / "Switch to Dark Mode".
4. Test responsive design in Chrome DevTools at 375px width.
5. Check Console for the TypeScript application's console messages.

If TypeScript is installed:
    npx tsc script.ts --target ES2020 --module none --outFile script.js

Assignment requirements covered:
- Dark/Light mode toggle
- CSS variables for theme colors
- classList.toggle
- getElementById
- addEventListener
- Smooth scrolling
- Responsive layout at 375px
- No horizontal scrolling
- Readable mobile text
- Skills stack to one column on very small screens / two columns on tablet-size mobile
- Google Fonts bonus
- Separate TypeScript source file
