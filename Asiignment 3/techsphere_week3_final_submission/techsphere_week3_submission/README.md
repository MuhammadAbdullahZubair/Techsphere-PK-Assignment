# Fixora Mobile Care — TechSphere PK Week 3

Fictional Pakistani business landing page for the TechSphere PK Web Development Virtual Internship, Batch 3, Week 3.

## Included
- Responsive `index.html`
- Professional `style.css`
- Form demo `script.js`
- Local SVG artwork + favicon in `images/`
- SEO title/description/Open Graph tags
- Descriptive image alt attributes
- Google Fonts (Space Grotesk + Manrope)
- Responsive layouts for desktop and 375px mobile

## Run locally
Open `index.html` in Chrome, or use VS Code Live Server.

The contact form is intentionally front-end only, matching the assignment brief.
