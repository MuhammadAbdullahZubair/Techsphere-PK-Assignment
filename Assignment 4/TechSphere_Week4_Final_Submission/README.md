# Fixora Mobile Care — TechSphere PK Week 4 Final Project

A fictional 4-page Pakistani business website created for the Web Development Final Project.

## Pages
- index.html — Home
- about.html — About
- services.html — Services + pricing
- contact.html — Contact + business details + form

## Shared files
- style.css — shared design system and responsive styles
- script.js — active navigation and demo form handling
- images/ — local SVG image assets and favicon

## Responsive targets
- Desktop: 1200px
- Mobile: 375px

## Hosting
Upload the contents of this folder to GitHub Pages or Netlify. No backend is required.

## Important
This project uses fictional business information and testimonials for internship/demo purposes.
